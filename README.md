## Featured Projects

### poserp — Multi-Tenant ERP & POS Platform
> *The most comprehensive project I've built. A full enterprise ERP system from scratch.*

A SaaS-based ERP and Point of Sale platform designed for small and medium businesses. Multi-tenant architecture means multiple businesses run on the same installation with fully isolated data. Built independently alongside university studies.

| Module | What it covers |
|--------|---------------|
| **Point of Sale** | Sales processing, invoicing, quotations, receipts |
| **Inventory** | Multi-warehouse stock, transfers, expiry tracking, cycle counts |
| **Accounting** | Double-entry bookkeeping, journal entries, financial reporting |
| **HR & Payroll** | Employees, PAYE calculation, payslips, automated payroll |
| **CRM** | Customer profiles, ledger, debt tracking, payment history |
| **Analytics** | AI sales forecasting, KPI targets, recommendation engine |
| **Automation** | Celery background jobs, scheduled reports, low stock alerts |
| **Notifications** | Email, SMS, and WhatsApp queue system |
| **SaaS Layer** | Tenant management, subdomain routing, superadmin panel |
|**python easy to understand documentation**|Detailed handbook in docx that makes it easy to understand python


`Python` `Django` `MySQL` `Celery` `Redis` `REST APIs` `Multi-tenancy`
